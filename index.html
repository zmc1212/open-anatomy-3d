关于本站 · 复刻说明

本站复刻自开源项目 MervinR07/open-anatomy-3d: 男 / 女两套全身模型,覆盖皮肤、骨骼、关节、肌肉、器官、血管、神经共 7 大系统、147 个命名结构 (含 12 个关节热点)。结构目录与 GLB 模型(EXT_meshopt 压缩)取自其 npm 包 open-anatomy-3d@0.1.0,模型改编自 BodyParts3D、HuBMAP 人体参考图谱与 MakeHuman,按 CC BY 4.0 署名使用(见页脚)。原版是 React + react-three-fiber 组件;本站改为 零构建 vanilla Three.js 实现,模型以 Base64 内置于 models/*.glb.js,因此支持 file:// 双击打开,并补充了全量中文译名。 交互与原版一致:悬停识别结构、点击固定 / 取消标注(卡片随视角跟随)、七层系统独立开关、 女性躯体含子宫 / 卵巢等专属器官。仅供教学演示,不用于诊断。 

npm i open-anatomy-3d open-anatomy-3d-react \
  three @react-three/fiber @react-three/drei

import { AnatomyViewer } from 'open-anatomy-3d-react'
import 'open-anatomy-3d-react/styles.css'

<AnatomyViewer
  pins={[{ key: 'heart', items: ['Hypertension'] }]}
  onStructureClick={(key, s) => console.log(key, s.label)}
/>
